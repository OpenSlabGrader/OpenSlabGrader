# OpenSlabGrader

Open-source grading of trading cards from flatbed scans.

OpenSlabGrader measures a card instead of eyeballing it. A card is scanned on an ordinary
consumer flatbed scanner, and the software measures what graders look at: centering, corners,
edges and the cut. Every number is written down with how it was measured, so a grade can be
rerun from the saved scan and checked by anyone.

## Status

Under development. The code is not yet published here. This repository holds the name, the
license and this note while the first release is prepared.

## What it is for

- Shops, graders and collectors who want a grade they can verify, not one they have to trust.
- English-language cards first; other cards as the project grows.
- Cheap, widely available scanners. No special hardware.
